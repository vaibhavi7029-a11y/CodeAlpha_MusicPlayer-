# 🎧 VibeWave – Music Player

A modern, responsive music player built using **HTML, CSS, and JavaScript** as part of the **CodeAlpha Frontend Development Internship**.

VibeWave provides a simple and interactive music listening experience with playback controls, playlist management, progress tracking, and volume adjustment.

## ✨ Features

- ▶️ Play and Pause music
- ⏮️ Previous and Next song navigation
- 🎵 Display song title and artist name
- ⏱️ Current time and total duration
- 📊 Interactive music progress bar
- 🔊 Volume control
- 📃 Interactive playlist
- 🔄 Automatic next-song playback (Autoplay)
- 📱 Responsive user interface
- 🎨 Modern dark theme with gradient styling

## 🛠️ Technologies Used

- **HTML5** – Structure of the music player
- **CSS3** – Styling, animations and responsive design
- **JavaScript** – Audio controls and playlist functionality
